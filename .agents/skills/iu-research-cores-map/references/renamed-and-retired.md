# Renamed, reorganized, and retired cores

Record a change here rather than deleting the old name. An agent that does
not see an old name listed may assume the core still exists under it.

Each entry says how it was observed. Where only a pattern suggests a change,
the entry says so and stays an open item until the core or IU confirms it.

| Old name or host | Now | Evidence | Status |
| --- | --- | --- | --- |
