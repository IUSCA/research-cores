# IU core facility catalog

**Observed 2026-10-04.** Each row was built from IU's core directories and,
where marked Verified, from the core's own website on that date.

This is a snapshot for matching research to cores. The core's own website is
the source of truth for services, rates, and how to request work. Read it
before telling anyone how to get access.

Status:

- **Verified.** The core's own page loaded on 2026-10-04 and shows this name
  and capability.
- **Listed.** A directory lists the core, but its own page did not load or
  does not exist. Confirm with the core before relying on it. Each is an open
  item in `docs/open-items.md`.

Directory codes, from `scripts/core_directories.py`: **M** IUSM Find a Core,
**C** Indiana CTSI Service Cores (**C\*** a CTSI Designated Service Core),
**L** IU iLab, **R** IU Research CIMS page, **A** College of Arts and
Sciences Facilities, **E** Research Equipment and Tools, **K** IU Simon
Comprehensive Cancer Center Shared Facilities.

Booking: "iLab" means the core appears on IU's iLab landing page. Other
values are what the core's page names. "Not stated" means neither.

No row names a person. Core pages list their own staff and contacts.
