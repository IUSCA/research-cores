# Technique to core map

**Observed 2026-10-04** from each core's own page, linked in the
`iu-research-cores-map` catalog. A technique listed here was named on the
core's page that day. Confirm with the core before planning around it.

"IUB" is IU Bloomington. "Indy" is IU Indianapolis and the IU School of
Medicine there.

## Nucleic acids

| Measurement | Technique | IU cores |
| --- | --- | --- |
| Transcript abundance, bulk | RNA-seq (mRNA, total RNA, ultra-low input, miRNA) | CMG (Indy); CGB (IUB) |
| Genome or exome variants | Whole genome or whole exome sequencing | CMG (Indy) |
| Small genomes, amplicons, methylation, ChIP, ddRAD | Illumina NextSeq and MiSeq, Nanopore | CGB (IUB) |
| Plasmid or PCR product sequence | Sanger, through vendor drop boxes | CGB (IUB) hosts drop boxes; it no longer runs Sanger itself |
| Expression per cell | Single-cell and single-nucleus sequencing, multiome | CMG (Indy) |
| Expression in tissue context | Spatial transcriptomics: Visium, Xenium | CMG (Indy) |
| Targeted RNA or protein panels in tissue | nCounter, GeoMx DSP | SNRI Biomarker Core (Indy) |
| Analysis of sequencing data | Bioinformatics, fee for service | Bioinformatics Core (Indy); Cancer Bioinformatics Core (Indy); CGB (IUB) |

## Proteins and small molecules

| Measurement | Technique | IU cores |
| --- | --- | --- |
| Protein identity in a band or pulldown | In-gel digestion, LC-MS/MS | Center for Proteome Analysis (Indy); LBMS (IUB) |
| Proteome-wide quantification | TMT labeling, fractionation, LC-MS/MS | Center for Proteome Analysis (Indy); LBMS (IUB) |
| Post-translational modifications | Phosphopeptide enrichment; glycosylation, acetylation, persulfidation | Center for Proteome Analysis (Indy); LBMS (IUB) |
| Protein-protein interactions | Affinity purification MS; crosslinking MS | Center for Proteome Analysis (Indy); LBMS (IUB) |
| Drug-target engagement | Thermal proteome profiling | Center for Proteome Analysis (Indy) |
| Plasma or fluid biomarkers, many at once | Olink proximity extension | Center for Proteome Analysis (Indy) |
| Many analytes in a microplate | Multiplex bead and plate assays | Multiplex Analysis Core (Indy); SNRI Biomarker Core (Indy); Translation Core (Indy) |
| Small-molecule identity and formula | Accurate-mass MS | Mass Spectrometry Facility (IUB); Chemical Genomics Core Facility (Indy) |
| Drug and metabolite concentrations | LC-MS/MS quantification, pharmacokinetics | Clinical Pharmacology Analytical Core (Indy) |
| Metabolite profiles | Untargeted or targeted metabolomics through vendors | Collaborative Metabolome Core (Indy) |
